# AIニケちゃん Live2Dモデルの利用案内

このフォルダの `nike01/` はAIニケちゃんの同梱Live2Dモデルです。モデルを取り出して他のアプリで使う場合も含め、利用前に以下の最新の条件をご確認ください。

- [公式Live2DモデルのREADME・利用条件](https://github.com/tegnike/nikechan-assets/blob/main/live2d/README.md)
- [二次創作ガイドライン](https://nikechan.com/guidelines/derivative)
- [AI生成ガイドライン](https://nikechan.com/guidelines/ai)
- [AITuberKitのモデル利用規約・制作者情報](../../docs/character_model_licence.md)

## 利用条件の要点

- 個人使用、非商用のデモンストレーション・紹介向けです。
- 商用利用（広告・投げ銭等を含む）、モデルの改変や派生作品の作成とそれらの配布、原本・改変版・抽出素材の再配布・他アプリ等への同梱は禁止です。
- **画像生成・AIへの入力・参照・学習・変換は禁止です。** モデル本体だけでなく、テクスチャ、付属データ、抽出・改変・変換データ、表示画像・動画・スクリーンショットも対象です。学習の有無、公開・非公開、商用・非商用を問いません。
- 素材自体をAIへ取り込まず、生成された会話や合成音声に合わせて表示・既存の表情・モーション・リップシンクを動かす通常のAITuber利用は、このAI利用禁止には当たりません。非商用等の条件は引き続き適用されます。

AITuberKit本体の商用ライセンスは、このモデルの商用利用・再配布を許可するものではありません。一般ガイドラインにある収益化・改変等の許可によってLive2D固有の制限が緩和されることはありません。この案内は要約です。詳細は上記リンク先の現行条件に従ってください。
