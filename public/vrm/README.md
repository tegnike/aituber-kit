# AIニケちゃん VRMモデルの利用案内

このフォルダに同梱しているAIニケちゃんのVRMモデルは、以下の公式利用条件を確認し、その範囲内でご利用ください。AITuberKit本体のライセンスとは別の条件が適用されます。

## 利用前に必ずご確認ください

詳しい利用条件・ガイドラインは、[AIニケちゃん公式アセットリポジトリ（nikechan-assets）](https://github.com/tegnike/nikechan-assets)で案内しています。モデルを取り出して他のアプリで利用する場合も含め、利用前に次の内容を必ずお読みください。

- [VRMモデルのREADME・利用条件](https://github.com/tegnike/nikechan-assets/blob/main/vrms/README.md)
- [二次創作ガイドライン](https://github.com/tegnike/nikechan-assets/blob/main/guidelines/derivative_creation_guideline.md)
- [AI生成ガイドライン](https://github.com/tegnike/nikechan-assets/blob/main/guidelines/ai_generation_guideline.md)

この案内は、新たな利用許諾や再配布許可を与えるものではありません。利用できる範囲、収益化、改変、再配布などの詳細は、リンク先の最新の案内に従ってください。

公式アセット側の案内に従い、VRMファイル内に埋め込まれた過去のライセンス・利用条件メタデータは適用せず、公式サイトの詳細版ガイドラインとアセット固有の現行条件を優先してください。

## 同梱モデルについて

| ファイル                    | 内容                         |
| --------------------------- | ---------------------------- |
| `nikechan_v1.vrm`           | 初期バージョン               |
| `nikechan_v2.vrm`           | 上着なし・軽量版（25MB未満） |
| `nikechan_v2_outerwear.vrm` | 上着あり・軽量版（25MB未満） |

上着あり・なしのv2モデルは、AITuberKitでの配信・読み込み向けに容量を抑えた軽量版です。通常版を利用したい場合は、[公式アセットリポジトリのVRMフォルダ](https://github.com/tegnike/nikechan-assets/tree/main/vrms)をご覧ください。通常版・軽量版ともに、公式の利用条件をご確認ください。

`AvatarSample_*.vrm` は別のサンプルモデルです。この案内のAIニケちゃん向け利用条件の対象には含まれません。
